# TAB 1 — ROI SELECTION

---

# What is ROI?

ROI = Region Of Interest

Meaning:

* the area you WANT to inspect.

Everything outside ROI is ignored.

Example:

```text
Whole image = 1000x1000

But only center region matters.
```

So you manually draw polygon around important area.

---

# STEP 1 — Load Image

Function:

```python
tab1_upload_image()
```

What happens:

1. User selects image
2. OpenCV reads image

```python
cv2.imread()
```

3. Image stored in memory

Variables:

```python
self.tab1_cv_image
self.tab1_image
```

# COMPLETE PIPELINE EXPLANATION

---

# STEP 0 — Original Image

Purpose:

* keep raw input image

No processing.

Just display image.

---

# STEP 1 — ROI Masking

Purpose:

# Remove unwanted areas.

---

# Why needed?

Outside ROI:

* noise may exist
* background may interfere

So:

* keep only important area.

---

# How it works

First create black mask:

```python
mask = np.zeros(...)
```

Then fill polygon:

```python
cv2.fillPoly()
```

Now polygon area becomes white.

---

# Result

```text
Inside ROI  → kept
Outside ROI → black
```

---

# STEP 2 — Grayscale Conversion

Purpose:

# Simplify image.

---

# Why grayscale?

Color image:

```text
3 channels
(R,G,B)
```

Grayscale:

```text
1 channel only
```

Easier for:

* thresholding
* segmentation
* morphology

---

# Conversion

```python
gray = cv2.cvtColor(...GRAY)
```

---

# STEP 3 — Sobel Gradient

Purpose:

# Detect edges.

---

# What Sobel does

Finds intensity changes.

Example:

```text
dark → bright
```

creates strong edge.

---

# Output

Bright regions:

* strong edges

Dark regions:

* smooth surfaces

---

# Why needed?

Watershed algorithm needs:

# elevation map

Sobel creates that elevation map.

---

# STEP 4 — Histogram Markers

Purpose:

# Identify probable foreground and background.

---

# Logic

Low intensity:

```text
background
```

High intensity:

```text
foreground
```

Using thresholds:

```python
low_threshold
high_threshold
```

---

# Example

If:

```text
low_threshold = 30
high_threshold = 150
```

Then:

```text
0–30   → background
150–255 → foreground
```

Middle values:

* uncertain region

---

# Output

Marker image.

Contains labels:

* foreground
* background

---

# STEP 5 — Watershed Segmentation

Purpose:

# Separate objects/regions.

---

# Simple understanding

Imagine:

* image is terrain
* water fills valleys

Watershed separates regions where water meets.

---

# Input

Needs:

* elevation map
* markers

---

# Output

Segmented regions.

Each region gets label.

Example:

```text
Region 1
Region 2
Region 3
```

---

# STEP 6 — Morphological Close

Purpose:

# Fill small gaps.

---

# Operation

```text
Dilation
then
Erosion
```

---

# Effect

Connects nearby broken regions.

Example:

Before:

```text
###   ###
```

After:

```text
#########
```

---

# STEP 7 — Morphological Open

Purpose:

# Remove small noise.

---

# Operation

```text
Erosion
then
Dilation
```

---

# Effect

Tiny particles disappear.

---

# STEP 8 — Fill Holes

Purpose:

# Fill empty spaces inside objects.

---

# Example

Before:

```text
#####
#   #
#####
```

After:

```text
#####
#####
#####
```

---

# STEP 9 — Connected Components

Purpose:

# Find separate blobs.

---

# Example

If image has:

```text
Blob A
Blob B
Blob C
```

Then:

* each gets unique label.

---

# Also removes tiny regions

Using:

```python
min_size
```

Small blobs ignored.

---

# STEP 10 — Final Classification

Purpose:

# Decide defect or non-defect.

---

# Logic

Measure contour area.

If area between:

```python
min_area
max_area
```

Then:

```text
valid defect
```

---

# Final decision

If valid defects found:

```text
DEFECT
```

Else:

```text
NON-DEFECT
```
